# Progress Log - Parishisht Construction Private Limited Corporate Web Portal

## Codebase Patterns
- **Brand Palette (Light Corporate EPC):** Luminous Architectural White (`#FFFFFF`), Off-White Slate Canvas (`#F8FAFC`), Deep Corporate Navy (`#071224`, `#0B192C`, `#0F4C81`), Royal Engineering Blue (`#2563EB`, `#1E40AF`), Saffron / Amber Gold (`#D97706`, `#B45309`), Laser Emerald (`#059669`). Benchmarked directly against Larsen & Toubro (L&T), RKDCPL, and MGCPL.
- **Custom Dropdown Architecture:** All form and filter `<select>` elements use `.custom-select` with an embedded SVG chevron arrow data URI, min-height 44px, >= 16px mobile font sizing, clean slate borders, and royal blue focus rings, ensuring consistent cross-device rendering on iOS Safari, Android Chrome, and Desktop.
- **Architecture Pattern:** Pure Single-Page Application (SPA) driven by centralized `ParishishtApp` reactive state store. Dynamic client-side rendering for project bento/table/corridor views, modal dossiers, parametric BOQ calculations, bidding capacity, fleet telemetry, and GIS operations radar.
- **Bilingual Reactivity:** 100% synchronized English & authentic Hindi translation dictionaries (`translations.en`, `translations.hi`) applying instant updates to static `data-i18n` elements and dynamic JavaScript render templates.
- **Terminology Standard:** Aligned strictly with Bihar Public Sector works (PHED, BUIDCO, RCD, RWD, Jal Jeevan Mission, CPWD/IRC standards).
- **Target Audience:** Tender evaluation committees, chief engineers, institutional bank partners, JV consortiums, civil engineering job applicants.
- **Wix Block Integration:** Page-by-page ready markdown with pre-formatted H1/H2, body paragraphs, and button configurations.
- **Mobile & Dual-Device Ergonomics:** Strict adherence to UI/UX Pro Max standards: all interactive touch targets >= 44x44px, inputs >= 16px to prevent iOS Safari auto-zoom, thumb-zone mobile bottom floating action dock with safe-area insets, horizontal inertial chip carousels for filters, responsive modals adapting to native bottom-sheets on mobile viewports, and non-blocking `touch-action: pan-y` on auto-scrolling conveyors.
